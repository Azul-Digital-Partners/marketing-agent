# Report Template

Claude Code fills this in when a task finishes or blocks. Write it into the same Agent Tasks row.

```
STATUS: [Delivered | Blocked]

OUTPUT:
- [file path in repo]
- [file path in repo]

WHAT I DID: [two or three lines]

DONE-WHEN CHECK:
- [each "Done when" line from the brief, marked met or not met]

GAPS: [every [NEEDS FACT] left in the draft, or "none"]

DECISION NEEDED: [one question for Nadia or Steven, or "none"]

IF BLOCKED: [what is missing and who can supply it]
```

Keep it short. Nadia reads twenty of these a week.
