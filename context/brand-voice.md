## Writing Style Guidelines

### Sentence Structure

- **Vary length**: Mix short, punchy sentences with longer expository ones.
- **Active voice preferred**: "We build X" — not "X is built by us."
- **Cut hedge words**: Replace "We help," "We support," "We strive to" with direct action verbs.

### Paragraph Structure

- **Length**: 1–4 sentences typical for web/blog. Single-sentence paragraphs are fine for emphasis.
- **One idea per paragraph**: If you can't summarize the paragraph in one sentence, split it.
- **Lead with the point**: Topic sentence first. Don't bury the conclusion.

## Quick Reference Card

When writing, ask:

1. Does this reflect one of our core voice pillars? If no, sharpen.
2. Could a competitor swap their logo onto this and have it still be true? If yes, rewrite — it's not specific enough.
3. Did I use any banned words? If yes, replace.
4. Did I bury the lede? If yes, lead with it.
